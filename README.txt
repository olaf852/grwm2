رفع الموقع على GitHub Pages:
1) أنشئي repository جديد (مثلاً makeup) وارفعي كل محتويات هالمجلد (index.html, looks.js, logo.png, مجلد images).
2) Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
3) الرابط بيصير: https://USERNAME.github.io/makeup/
لإضافة لوك: ارفعي الصورة لمجلد images وعدّلي looks.js على GitHub (أيقونة القلم).
